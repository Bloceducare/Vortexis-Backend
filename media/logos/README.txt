VORTEXIS LOGO KIT
=================

WHICH FILE SHOULD I USE?
  Website / app UI ........ svg/  (scales infinitely, smallest file size)
  Slides, docs, email ..... png/logo/ (transparent background)
  Print / merch ........... pdf/  (vector, CMYK conversion left to your printer)
  Browser tab / PWA ....... favicon/ (see favicon/head-snippet.html)
  Link previews ........... social/og-image-1200x630.png

LOGO VARIANTS
  color     - for light backgrounds (violet / teal / navy mark, navy text)
  reversed  - for dark backgrounds (violet / cyan / ice mark, white text)
  black     - one-colour, for light backgrounds
  white     - one-colour, for dark or photo backgrounds
  tagline   - lockup with "RUN . JOIN . WIN" (color and reversed only)

All PNGs have transparent backgrounds (except the OG image, avatar,
apple-touch-icon and maskable icon, which are intentionally full-bleed navy).
Sizes in file names: "-2000w" = 2000 px wide. Marks and icons are square.

NO QUALITY LOSS
  All SVG/PDF files are pure vector paths. The "VORTEXIS" wordmark is
  converted to outlines, so no font installation is needed and it will
  render identically everywhere. PNGs are rendered directly from the vector
  geometry at each size (never upscaled).

BRAND COLORS
  Navy ......... #0B1020
  Violet ....... #7C5CFF (on dark)   #6A4BFF (on light)
  Cyan ......... #22D3EE (on dark)   #0891B2 (on light)
  Ice .......... #E8EAFF
  Muted text ... #A9B0D0 (on dark)   #4A5070 (on light)

USAGE
  Clear space: keep at least 15% of the mark's height free on all sides.
  The SVG/PNG files already include this margin.
  Minimum size: lockup 120 px wide, mark 16 px (use favicon/ files below 32 px).
  Don't recolor, rotate, stretch, or add effects.

TYPOGRAPHY
  Wordmark: Inter Bold, +8% tracking, outlined (Inter is open source, SIL OFL).
  Tagline: Inter Medium, +28% tracking.
